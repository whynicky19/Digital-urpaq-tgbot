# 🤖 Telegram-бот Digital Urqaq

## 🚀 Быстрый запуск (3 шага)

### Шаг 1: Установить зависимости
```bash
pip install aiogram==3.7.0
```

### Шаг 2: Настроить бота
Открой `bot.py` и измени две строки вверху:

```python
BOT_TOKEN = "ВСТАВЬ_СЮДА_СВОЙ_ТОКЕН"    # Получить у @BotFather -> /newbot
ADMIN_IDS = [123456789]                   # Твой Telegram ID (узнать у @userinfobot)
```

### Шаг 3: Запустить
```bash
python bot.py
```

---

## 📋 Что умеет бот

### Для учащихся/родителей:
- 📚 Просмотр всех кружков с деталями (расписание, места, преподаватель)
- 📝 Подача заявки на кружок (пошаговая форма)
- 📋 Просмотр своих заявок и их статусов
- 📰 Чтение новостей и объявлений
- ℹ️ Информация о Дворце и контакты

### Для администратора:
- 📋 Просмотр всех заявок
- ✅ Управление статусами заявок (одобрить / отклонить / в ожидании)
- 📢 Публикация новостей
- ➕ Добавление новых кружков
- 📊 Статистика

### Автоматически:
- Уведомление админа о новой заявке
- Уведомление учащегося об изменении статуса заявки
- База данных SQLite (файл `digital_urqaq.db` создаётся автоматически)
- Тестовые данные (5 кружков, 2 новости) добавляются при первом запуске

---

## 📁 Файлы
- `bot.py` — основной файл бота
- `requirements.txt` — зависимости
- `digital_urqaq.db` — база данных (создаётся автоматически)

## ⚙️ Технологии
- Python 3.10+
- aiogram 3.7 (FSM, InlineKeyboard, ReplyKeyboard)
- SQLite3 (встроен в Python, ничего не нужно устанавливать)
